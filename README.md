# Mic USB Bridge

Приложение передаёт микрофон Windows-компьютера на телефон по локальному IP-соединению, которое создаёт USB-модем. Интернет для передачи не нужен: трафик идёт по USB-сетевому интерфейсу.

## Состав

- `android/` — нативный Android-клиент на Java — **приёмник**. Слушает UDP-порт и воспроизводит моно PCM 16-bit / 48 kHz через `AudioTrack`.
- `windows/mic_usb_client/main.py` — Windows-клиент на Python/PySide6 — **отправитель**. Захватывает **системный звук** (WASAPI loopback через `soundcard`) или микрофон (Qt `QAudioSource`), режет на блоки по 10 ms и шлёт UDP; `QSystemTrayIcon` для трея.
- `windows/requirements.txt` — зависимости Python-клиента.
- `protocol/PROTOCOL.md` — описание бинарного формата.
- `dist/` — переданные пользователем CSS/SVG-материалы, сохранённые как референс.

## Запуск

1. На телефоне включите **USB-модем** и подключите кабель.
2. Установите ПО на Windows (PowerShell в папке `windows`):

```powershell
py -m pip install --upgrade pip
py -m pip install -r requirements.txt
```

3. На телефоне откройте приложение и нажмите «НАЧАТЬ ПРИЁМ». В карточке будет виден IP телефона (обычно `192.168.42.129`).
4. На ПК запустите клиент: `py .\\mic_usb_client\\main.py` (окно живёт в трее — «Открыть» через иконку).
5. Укажите IP телефона и порт `42042`, выберите источник («Системный звук: …» — всё, что играет на ПК, или микрофон), нажмите «НАЧАТЬ ПЕРЕДАЧУ».

Закрытие окна Windows-клиента сворачивает его в трей. Для полного выхода выберите «Выход» в меню иконки. Если Windows не отдаёт микрофон, проверьте «Параметры → Конфиденциальность → Микрофон» (доступ для классических приложений).

## Сборка Android

Требуется Android Studio или Android SDK + Gradle 8.7. Из каталога `android` выполните `gradle assembleDebug`. APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Зависимости Python-клиента

- `PySide6` — интерфейс, системный трей и Qt Multimedia `QAudioSink` для вывода PCM.

Если Windows сообщает, что не найден модуль `PySide6`, установка выполнена не тем Python: используйте одну и ту же команду `py -m pip` и `py .\\mic_usb_client\\main.py`. Если приложение запускается, но нет звука, выберите обычное устройство вывода Windows по умолчанию и проверьте, что порт `42042` разрешён для частной сети в Firewall.

## Задержка и качество

Размер аудиофрейма — 480 сэмплов (10 ms). Приёмник держит маленький буфер сокета (~16 КБ) и `AudioTrack` с режимом LOW_LATENCY. UDP выбран для отсутствия повторных задержек TCP; при потерях пакетов возможны короткие щелчки (счётчик потерь виден на телефоне).

Это рабочий MVP-прототип. Для production-версии стоит добавить шифрование/аутентификацию, автоматическое обнаружение ПК, выбор конкретного аудиоустройства и режим WASAPI exclusive.
